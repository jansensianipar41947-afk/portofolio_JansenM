Detailed S-1 Thesis Breakdown

Comparative Analysis of LSTM vs GRU with Hyperparameter Optimization for Air Pollution Trend Prediction

1. Background & Problem Statement

Air pollution from campus motor vehicle movements triggers extreme micro-scale particulate fluctuations (PM2.5 & PM10). Standard macro government monitoring stations cannot capture these localized spikes in real-time. This study built a custom IoT acquisition node (NodeMCU ESP8266 + PMS5003T laser sensor) transmitting data at 1-minute intervals to ThingSpeak cloud storage.

2. Methodology & Preprocessing Pipeline

  • Data Cleaning: Outlier removal for readings >300 µg/m³ (eliminating electrical hardware glitches).
  • Data Augmentation: Solved ISPU class imbalance by integrating peer data and applying Gaussian Noise injection & local linear interpolation (reaching 3,557 balanced rows).
  • Sequencing: Formed 3D sequential sliding windows [samples, 10 timesteps, 2 features].
  • Hyperparameter Tuning: Exhaustive Grid Search over Epochs {50, 100} and Batch Sizes {32, 64}.

3. Quantitative Evaluation Summary

LSTM Model (50 Epochs, 64 Batch): • RMSE: 17.7647 µg/m³
• MAE: 10.1312 µg/m³
• Test Inference RAM: 34.77 MB
GRU Model (50 Epochs, 64 Batch): • RMSE: 18.1988 µg/m³
• PM10 ISPU Acc: 85.30% (F1: 85.37%)
• Test Inference RAM: 5.91 MB

4. Practical Recommendation for HR & Tech Teams

Although LSTM yields slightly lower regression error, GRU is definitively recommended for edge deployment on NodeMCU ESP8266 due to its 6x lower memory footprint (5.91 MB vs 34.77 MB) preventing Out-of-Memory (OOM) system crashes.
